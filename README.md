# **Description**
### This repo contains basic scripts and files for personal use on my Gentoo Linux system.
Usage:
It is highly recommended to keep the scripts and files used by them in hidden folders. If you choose to keep the paths I use for the files used by scripts then you must make the required directories:
sudo mkdir -p "/.Files used by personal scripts/files used by crontab's daily HDD defrag operation"
sudo mkdir -p "/.Files used by personal scripts/files used by crontab's daily SSD fstrim operation"
else if you don't like the names (you might not prefer spaces in file paths especially in scripts) you must edit them in the scripts and run the commands above with those new paths.
For the crontab file to work, the scripts used there must be in:
/.scripts_for_personal_use/
that is unless you change the path yourself, of course.
